# Onkar Shinde — Personal Portfolio

## About

A personal portfolio website built from scratch using only **HTML** and **CSS**.
Designed to showcase who I am, the skills I'm learning, and the projects I've built.

## Technologies

- HTML5 (Semantic elements)
- CSS3
  - Flexbox
  - CSS Grid
  - CSS Animations & Keyframes
  - CSS Transitions & Transforms
  - Responsive Design (Media Queries)
  - CSS Custom Properties (Variables)
  - Positioning (fixed, relative, absolute)
